# EnggXR mobile

The EnggXR mobile app is an Expo and React Native project for Android and iOS.

## Run locally

1. Run `npm install` in this folder.
2. Run `npm start`.
3. Scan the QR code with an Expo development build, or launch an Android or iOS simulator.

## Current milestone

- Public entry screen
- Three-step student onboarding
- Home summary
- Branch exploration
- College matches and shortlist controls
- Student profile view
- Phone and tablet layouts

College data is demonstration data and must be replaced with official sources before launch.
